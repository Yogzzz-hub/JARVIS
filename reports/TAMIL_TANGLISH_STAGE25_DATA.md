# Stage 2.5 Tamil/Tanglish corpus build

**Status: 30,000 machine-validated Q2 candidates built; independent audit pending.** Q2 means deterministic validation passed. It does not mean a human reviewed the row or that Tamil naturalness and semantic labels are proven.

`python -m scripts.stage25_generate` starts from compatible action/object programs and realizes Tamil and Tanglish utterances separately. It generated 70,160 rows including ASR children, rejected 354 duplicate utterance/context combinations, and retained a 69,806-row validator-passed pool. Constrained family-aware selection produced **18,000 Tanglish + 12,000 Tamil** candidates. The selected file is ignored by Git at `data/tanglish/generated/stage25/stage25_candidates.jsonl`, SHA-256 `0e826b3f24a768029efe74d5044104f7831cb76a1e9006ab529c822f25a4b1bf`. Two fresh runs produced the same selected-file hash. The original authored seed remains separate.

The selected corpus spans **1,884 construction families**, **16,842 distinct labelled semantic frames**, 56 supported ActionConcept labels plus `None` for true non-action speech, and all 13 SpeechActs. There are **12,000 cross-script paired families**, 3,722 context-dependent rows, 1,500 clean-parent ASR/spelling rows, 1,866 corrections, 4,436 negated commands, and 238 explicitly ambiguous requests. Context examples now include active threads, apps, projects, browser tabs, and previous results. The historical-PDF example retains sender, date, ordinal, recipient, PDF type, and screenshot exclusion.

All **33 slot names** have at least 100 annotations; the sparsest, `date_range`, has 118. SEND is 1,873 rows, while SEND + SHARE + FORWARD total 2,659/30,000 (8.86%). The ten largest construction families account for 4.76% of rows, with no family above 250. The [ontology coverage audit](STAGE25_ACTION_ONTOLOGY_COVERAGE.md) classifies all 62 known concepts, and the [final distribution report](TAMIL_TANGLISH_STAGE25_FINAL_DISTRIBUTION.md) records action-object coverage, slot combinations, polysemy proxies, duplicate checks, and remaining sparse areas. These counts establish coverage, not naturalness or model accuracy.

Existing licensed public sources remain separate. The [public-source manifest](../data/tanglish/DATASET_MANIFEST.md) records canonical revisions, licenses, original hashes, row counts, and transformations. Eligible Aksharantar Tamil publisher-train rows provide word-level spelling/transliteration evidence; DravidianCodeMix supplies aggregate script and code-mix distribution. TanglishSTS and TamilTech-QA remain evaluation-only or quarantined as previously audited. No public comment was assigned a JARVIS command label, and no private conversation was used.

No pure-English command data was added. The original TEST and sealed HOLDOUT were not opened.
