# Personal WhatsApp style

The existing personal reply store keeps per-contact sources, examples, profiles and versions. Only genuine owner-authored or owner-edited final messages may count as style evidence. Incoming contact text, AI drafts, automated replies and unknown historical outgoing authorship cannot be treated as owner style. Generated message IDs and hashes help distinguish JARVIS echoes from owner text.

Profiles describe language mix, length, formality, punctuation and expressions. Contact evidence is preferred; low evidence reduces confidence and should fall back conservatively. Style is wording guidance, never authority for a factual claim or permission to send.

The provenance and profile machinery has local tests. No independent quality review of the linked account's current contact profiles was run. Read-only mode can inspect stored profiles but cannot auto-send.
