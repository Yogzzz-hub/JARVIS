# Blind-10: 50 unseen commands per phase, strict right-action scoring

Report generated by `python -m tests.blind10.report`. The set is in `tests/blind10` (frozen with `FROZEN.sha256` before its first run).

## How it was scored

- **Unseen.** 1,100 commands, 50 in each of 22 phases (the 21 Phase-500 areas plus browser automation).
  - They were written new for this test.
  - Every one was checked against every earlier test file, and none appears there word for word.
  - No fix was made between writing them and running them.
- **Right action, not just any action.** A command is correct only when the right tool is chosen *and* its arguments contain the right details (the app, the person, the number, the query, the file).
- **Must-not-act commands.** Each phase has commands that must *not* act: dangerous, vague or chat. Acting on them counts against precision.
- **Metrics:**
  - **Accuracy:** correct outcomes / all commands.
  - **Precision:** right actions / all actions JARVIS took. Doing the wrong thing lowers it.
  - **Recall:** right actions / commands that needed an action. Asking or handing over instead lowers it.
  - **F1:** the harmonic mean of precision and recall.
  - **Critical:** a wrong action that is consequential (delete, send, close, install, power ...).
- **Router only, no AI model.** Commands the router hands to the local model (Ollama) count as misses here, because this run has no model. With Ollama running, some of them would be answered or planned correctly. That part is not measured.
- **Same author.** I wrote this set and the router's rules, which may still flatter the numbers.
