# Agents and skills

Existing `AgentRunner`, planner and scheduler remain authoritative. No foreign agent runtime was imported. `SkillSpec` describes version, trust, capability requirements, preconditions, postconditions, risk and benchmark reference. UNREVIEWED skills cannot be enabled; required capabilities must be inside the approved set. This metadata is not a permission grant.

The skill executor/import workflow, discovery CLI and new specialist agents requested in the master specification are not complete. Existing registered project, research and communication tools retain their current behavior and safety controls. MCP remains disabled unless separately configured and validated.
